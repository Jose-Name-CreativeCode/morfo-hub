# Plantilla de incidencias QA

Yo uso esta plantilla para anotar fallas reales mientras uso Morfo Hub durante
la semana.

## Registro rápido

- Fecha:
- Usuario:
- Módulo:
- Acción que yo estaba haciendo:
- Resultado esperado:
- Resultado real:
- ¿Se perdió información?:
- ¿Se duplicó algo?:
- Prioridad:
- Captura o nota adicional:

## Prioridades sugeridas

- `Alta`: yo no puedo seguir trabajando o se pierden datos
- `Media`: yo sí puedo seguir, pero el flujo se vuelve lento o confuso
- `Baja`: detalle visual, texto, acomodo o mejora menor

## Ejemplo

- Fecha: 2026-06-03
- Usuario: Jose
- Módulo: Cotizaciones
- Acción que yo estaba haciendo: Yo guardé una cotización nueva como aprobada
- Resultado esperado: Yo esperaba ver el ingreso relacionado en Cobros e ingresos
- Resultado real: El ingreso no apareció hasta que recargué
- ¿Se perdió información?: No
- ¿Se duplicó algo?: No
- Prioridad: Media
- Captura o nota adicional: Revisar sincronización inmediata después de guardar
